# 🎙️ 複数音声ファイル文字起こし・分析プログラム

このプログラムは、複数のm4a音声ファイルを一括処理して、文字起こしと発話分析を自動実行するAIツールです。

## ✨ 何ができるの？

複数の音声ファイルから以下の分析を自動実行します：

1. **文字起こし** - 各音声ファイルの内容をテキスト化
2. **発話時間測定** - 無音部分を除いた実際の発話時間を計算
3. **発話割合算出** - 発話時間/総時間の割合を計算
4. **発話速度測定** - 文字数/10秒の発話速度を算出
5. **比較分析** - 複数人の結果を比較・可視化

## 📈 結果の見方

### 個別文字起こしCSV
- 各人の発話内容を完全にテキスト化
- ExcelやGoogleスプレッドシートで開けます

### 発話速度比較
- **文字数/10秒** の単位で表示
- 値が高いほど早口、低いほどゆっくり話している
- 一般的には30-60文字/10秒が標準的

### 発話割合比較
- **パーセンテージ（%）** で表示
- 音声ファイル中で実際に話している時間の割合
- 無音部分やノイズの時間は除外されます

### 統計情報
コンソールに表示される詳細統計で以下を確認できます：
- 平均発話速度・割合
- 最高・最低値とその人名
- 各人の詳細データ

## ⚠️ よくある問題と解決方法

### 「m4aファイルが見つかりません」エラー
```
❌ エラー: m4aファイルが見つかりません
   input ディレクトリにm4aファイルを配置してください
```
**解決方法:** `input/` フォルダに正しい形式のm4aファイルがあるか確認

### ファイル名形式エラー
**正しい形式:** `audio岸本智行21315332608.m4a`
**間違った形式:** `岸本智行.m4a`, `audio_岸本.m4a`

### メモリ不足エラー
**解決方法:** 
- 他のアプリケーションを閉じる
- ファイル数を減らす（一度に処理するファイル数を制限）

### 日本語文字化け
**解決方法:** CSVファイルをExcelで開く際は「UTF-8」エンコーディングを選択

## 🔒 プライバシーについて

- 音声データはローカル環境のみで処理
- インターネットへの音声アップロードはありません
- AIモデルのダウンロード時のみネット接続が必要
- 処理結果はすべてローカルに保存

## 🛠️ 高度な設定

### CPU最適化
プログラムはCPU効率を重視して設計されています：
- マルチスレッドは制限（安定性重視）
- プログレスバーで処理状況を可視化
- メモリ使用量を最小化

### カスタマイズ可能な設定
プログラム内で以下の設定を調整できます：
- 無音判定の閾値（`silence_thresh`）
- 最小無音時間（`min_silence_len`）
- Whisperモデルの種類（`medium` ↔ `small/large`）
